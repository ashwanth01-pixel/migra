For generating X-Credentials header it's necessary to have two types of credentials, one for GIT protocol access and another - for HTTP REST access. Both depend on SCM tool that you want to access. 
{
  "git": "git credentials", // ex. "username password"
  "proxy": "rest api credentials" // ex. "Authorization Basic dXNlcm5hbWU6cGFzc3dvcmQ="
}
To get the token, this JSON should be Base64 encoded. The converted string can be used as a value for X-Credentials header.
